# 하루기록 (웹)

운동·식단·수면·몸 기록을 **내 기기에만** 저장하는 기록 앱의 웹 버전입니다.

- 주소: https://taeinlee-snu.github.io/haru-web/
- 아이폰: Safari로 열고 공유 → **홈 화면에 추가**
- 안드로이드: Chrome으로 열고 ⋮ → **홈 화면에 추가** (또는 앱 설치)

기록은 서버로 보내지 않고 각자의 브라우저에만 저장돼요. 브라우저 데이터를 지우면 함께 지워지니 앱 안의 **백업 · 복원**으로 가끔 백업 파일을 저장하세요.

이 저장소는 배포용 결과물만 담고 있어요. 소스는 비공개 저장소에서 `web/build.py`로 만들어 올립니다.
